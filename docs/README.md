# База знаний pet_engine

Документы движка: что он умеет, как устроен, каким API пользуются
приложения и какие правила нельзя нарушать. Пишутся без сленга и с
расчётом на чтение через год.

## Документы

| Документ | О чём |
|---|---|
| [api.md](api.md) | Публичный API: `SceneViewport`, `SceneController`, `SceneNode`, материалы, камеры, ввод, попадания, качество, многогранники. |
| [features.md](features.md) | Реестр фич: что обязано быть в API, с примерами и ссылками на код. |
| [architecture.md](architecture.md) | Устройство движка: слои, модули, правила зависимостей. |
| [conventions.md](conventions.md) | Священные конвенции: зеркальный X, билборды, форматы, намотка граней. |
| [visual_testing.md](visual_testing.md) | Методика визуальной проверки сцен. |
| [perf_journal.md](perf_journal.md) | Замеры производительности и быстрые пути обновления сцены. |

## Пакет

Корень репозитория — сам пакет `pet_engine` (публичный вход —
`lib/pet_engine.dart`). Приложение-пример — `example/`, общий форк
`flutter_scene` — `third_party/flutter_scene` (обычный каталог, без своего
git-репозитория). История версий пакета — `CHANGELOG.md` в корне.

## Внешние источники

- История v1: репозиторий `npu3pak/flutter-pet-engine` (ветки `develop`,
  `feature/*`). Сам каталог v1 удалён из рабочего пространства; его
  документы остались в истории того репозитория.

## Правила

- Документ — источник истины: расхождение с кодом сначала правится в
  документе, потом в коде.
- Изменения форматов, рендера или конвенций требуют обновления
  `conventions.md` и тестов.
- Коммиты — только по явной просьбе владельца, сообщения на русском.
