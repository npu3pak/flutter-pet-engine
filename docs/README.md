# Единая база знаний pet_engine_v2

Здесь собраны документы о новом движке: зачем он, как устроен, каким будет
его API и как на него перейти. Документы пишутся без сленга и с расчётом на
чтение через год.

## Документы

| Документ | О чём |
|---|---|
| [plan.md](plan.md) | Идея владельца, её интерпретация, фазы работ. Главный документ. |
| [features.md](features.md) | Реестр фич: что обязано быть в API, с примерами и ссылками на код. |
| [architecture.md](architecture.md) | Устройство движка v2: слои, модули, правила зависимостей. |
| [api.md](api.md) | Публичный API: `SceneViewport`, `SceneController`, `SceneNode`, контроллер качества. |
| [migration.md](migration.md) | Карта перехода «v1 → v2» и порядок миграции потребителей. |
| [tz.md](tz.md) | Техническое задание для контекста реализации: объём, порядок, приёмка. |
| [handoff.md](handoff.md) | Передача контекста: состояние и следующие шаги (финальная приёмка). |
| [conventions.md](conventions.md) | Священные конвенции: координаты, билборды, форматы. |
| [visual_testing.md](visual_testing.md) | Методика визуальной проверки сцен. |

## Внешние источники

- Репозиторий v1: `../../pet_engine` — текущий движок, редактор и
  приложение-пример. Его документы остаются актуальными для v1:
  `../../pet_engine/docs/engine.md` (устройство v1),
  `../../pet_engine/docs/migration_math_quest.md` (история унификации),
  `../../pet_engine/docs/perf_journal.md` (измерения производительности).
- Общий форк: `../../flutter_scene` — отдельный репозиторий, общий для v1,
  v2 и всех проектов.
