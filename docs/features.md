# Реестр фич pet_engine_v2

Документ перечисляет всё, что обязано быть в API нового движка, чтобы при
переходе на v2 ни один из четырёх проектов не потерял возможностей. Реестр
собран из фактического кода: каждый пункт подтверждён ссылками
`файл:строка`.

## 1. Как читать документ

Обозначения проектов:

- **EN** — старый движок `pet_engine/engine`;
- **FS** — общий форк `flutter_scene/packages/flutter_scene`;
- **EX** — приложение-пример `pet_engine/engine/example`;
- **MQ** — игра `math_quest`;
- **PD** — игра `mypet-game/pet_demo`;
- **ED** — редактор `pet_engine/tools/scene_editor`.

Статус каждой фичи показывает, покрывал ли её черновик API на момент
составления реестра (до фазы проектирования):

- **покрыто** — выражается текущими типами и методами;
- **частично** — похожий примитив есть, но не хватает деталей;
- **нет** — API отсутствует.

Реестр — это список требований: все пункты «частично» и «нет» вошли в
итоговый публичный API (`docs/api.md`). Статусы ниже остаются как история
инвентаризации и не означают, что чего-то не будет в v2.

Формат записи: название, что делает, где используется, что нужно в API v2,
статус.

## A. Сессия, ресурсы, загрузка

### A1. Инициализация движка

- **Что делает.** Ожидание статик-ресурсов рендера (шейдерный бандл) до
  создания сцены; без этого построение геометрии падает.
- **Где.** `EX/lib/main.dart:15`, `PD/lib/main.dart:11`,
  `MQ/lib/engine/impl/scene_dungeon_renderer.dart:115`,
  `ED/lib/src/ui/editor_viewport.dart:85`,
  `ED/lib/src/ui/resources/model_viewer_screen.dart:216`.
- **API v2.** `initializeEngine()` остаётся публичным; вьюпорт сам ждёт
  готовности до первого кадра, приложению не нужно следить за порядком.
- **Статус.** Нет.

### A2. Источник проекта

- **Что делает.** Байты проекта из папки, ассетов Flutter или собственного
  источника; признак «можно писать»; имя для интерфейса.
- **Где.** `EN/lib/src/engine/project_source.dart:15` (`ProjectSource`),
  `:45` (`DirectoryProjectSource`), `:100` (`BundleProjectSource`);
  `MQ/lib/engine/impl/biome_project_source.dart:15-119` (своя реализация:
  дерево исходников на macOS, иначе `AssetManifest`);
  `PD/lib/main.dart:40-56` (выбор источника по `dart-define`).
- **API v2.** Типы остаются публичными; `SceneController.open(source)`.
  Своя реализация `ProjectSource` должна быть явно поддержана.
- **Статус.** Частично (в черновике нет `writable`, `label` и описания
  собственных источников).

### A3. Открытие проекта и каталог моделей

- **Что делает.** Чтение `project.json`, всех `models/*.json`, ключей
  ресурсов и каталога `3d_models/`; ошибки разбора не фатальны и
  перечисляются.
- **Где.** `EN/lib/src/engine/game_resource_manager.dart:62-110`;
  `PD/lib/src/game_screen.dart:108-115` (выбор `model_2`),
  `MQ/lib/engine/impl/biome_project_source.dart:124-131`.
- **API v2.** `SceneController.open/openProject/openModels`, ресурсная
  сессия с `projectName`, `modelIds`, `models`, `loadErrors`.
- **Статус.** Частично.

### A4. Каталоги ресурсов

- **Что делает.** Список текстур и спрайтов, чтение произвольного файла
  проекта, запись каталога `3d_models` (путь к источнику glTF).
- **Где.** `PD/lib/src/game_screen.dart:469,516,534,792`;
  `EX/lib/src/features/gltf_models.dart:22`;
  `EN/lib/src/engine/game_resource_manager.dart:110-147`.
- **API v2.** Методы ресурсной сессии: `textureKeys`, `spriteKeys`,
  `readBytes`, `gltfEntry`, `texture(key)`, `sprite(key)`.
- **Статус.** Нет.

### A5. Сохранение модели

- **Что делает.** Запись `models/<id>.json`; для read-only источника —
  отказ и сообщение.
- **Где.** `PD/lib/src/game_screen.dart:545-555`;
  `EN/lib/src/engine/game_resource_manager.dart:118-124`.
- **API v2.** `SceneController.saveModel()`, `resources.writable`,
  `controller.modelId`.
- **Статус.** Нет.

### A6. Асинхронный glTF и текстуры

- **Что делает.** Ленивый импорт glTF при первом показе, уведомление о
  готовности и автоматическая пересборка контента; клипы анимаций пусты до
  загрузки; размеры (bounds) объекта уточняются по факту импорта; при
  импорте исправляются BLEND-материалы glTF.
- **Где.** `EN/lib/src/services/gltf_asset_store.dart:104-128,170-221`;
  `EN/lib/src/engine/game_scene.dart:105,445-456,577-581`;
  `PD/lib/src/game_screen.dart:951-954` (интерфейс ждёт клипы).
- **API v2.** Контроллер сам пересобирает сцену при готовности; нода
  `ModelNode` отдаёт `animationClips`, `gltfName`, `gltfBounds` и
  уведомляет об изменении.
- **Статус.** Частично.

### A7. Подмена текстур внутри glTF

- **Что делает.** Перекраска ресурса: URI внутри папки glTF заменяется на
  другие байты, кэш импорта сбрасывается, сцена пересобирается; сброс
  возвращает оригинал.
- **Где.** `PD/lib/src/game_screen.dart:528-543`;
  `EX/lib/src/features/gltf_models.dart:83-98`;
  `EN/lib/src/engine/game_resource_manager.dart:133-143`.
- **API v2.** `resources.setGltfTextureOverride/clearGltfTextureOverride`,
  событие «ресурс изменился» и автоматическая пересборка.
- **Статус.** Нет.

### A8. Инвалидация и перезагрузка ресурсов

- **Что делает.** Сброс кэшей текстур и glTF после внешних изменений;
  повторное чтение моделей.
- **Где.** `EN/lib/src/engine/game_resource_manager.dart:105-131`;
  `PD/lib/src/game_screen.dart:541` (`rebuildContent` после подмены).
- **API v2.** `SceneController.reloadResources()`, `rebuild()`.
- **Статус.** Частично.

### A9. Статус загрузки

- **Что делает.** Пять стадий загрузки уровня (`проект → модели →
  ресурсы → геометрия → запекание`), доля готовности, подпись, список
  ошибок «ресурс + причина», время загрузки. Интерфейс показывает прогресс
  и ошибки, пока играет предыдущее состояние.
- **Где.** `EN/lib/src/level/level_loader.dart:8-53`;
  `MQ/lib/engine/impl/scene_dungeon_renderer.dart:462-499`;
  `MQ/lib/engine/core/level_load_state.dart:1-67`;
  `EX/lib/src/features/level_loading.dart`.
- **API v2.** `SceneLoadStatus` со стадиями, долей, подписью, ошибками;
  `SceneViewport.loadingBuilder`.
- **Статус.** Частично (в черновике только idle/loading/ready/error).

### A10. Предзагрузка дополнительных ресурсов

- **Что делает.** До показа уровня загружаются атласы травы, тумана и
  погоды, чтобы первый кадр не был с заглушками.
- **Где.** `EN/lib/src/level/level_loader.dart:89` (`LevelExtraResource`);
  `MQ/lib/engine/impl/scene_dungeon_renderer.dart:416-419`.
- **API v2.** `LevelExtraResource` и его подключение через
  `SceneController.loadLevel(...)`.
- **Статус.** Нет.

### A11. Защита от гонок при смене сцены и проекта

- **Что делает.** Устаревшие результаты асинхронных загрузок отбрасываются:
  счётчики поколений при пересборке этажа, при смене биома, при загрузке
  текстур и неба.
- **Где.** `MQ/lib/engine/impl/scene_dungeon_renderer.dart:381-460,501-524`;
  `MQ/lib/engine/impl/texture_store.dart:29-37`;
  `MQ/lib/engine/impl/scene_dungeon_renderer.dart:131-150` (небо).
- **API v2.** Контроллер сам управляет поколениями; приложение не пишет
  счётчики и не сравнивает пути вручную.
- **Статус.** Частично.

### A12. Скриншоты и анализ кадра

- **Что делает.** Снимок вьюпорта в PNG + JSON-карточка, анализ
  заглушек (фуксия/серый) и наполненности кадра; работает при скрытом окне.
- **Где.** `EN/lib/src/visual/screenshot.dart:21-257`;
  `MQ/lib/debug/scene_capture.dart:1-39`;
  `EX/lib/src/screenshot_saver.dart:10-48`.
- **API v2.** `SceneViewport.capture` (PNG-снимок вьюпорта),
  `saveScreenshot`, `analyzePlaceholders`, `analyzeFrameContent`.
- **Статус.** Нет.

### A13. Build-hook материалов

- **Что делает.** В `hook/build.dart` приложения вызывается движковая
  обёртка, компилирующая `.fmat` в шейдерный бандл (или инициализирующая
  пайплайн, если `.fmat` нет).
- **Где.** `EN/lib/build_hooks.dart:25` (`petBuildMaterials`);
  `PD/hook/build.dart:8`; `MQ/hook/build.dart:11`;
  `ED/hook/build.dart:15`.
- **API v2.** Контракт сохраняется; в документации API должен быть явно
  описан.
- **Статус.** Нет.

## B. Документ `model_v1`

### B1. Типы документа

- **Что делает.** Сцена как сериализуемый документ: объекты, мета-объекты,
  свет, материалы, группы, размеры; сериализация без потерь.
- **Где.** `EN/lib/src/models/model_scene.dart`;
  `EN/lib/models.dart` (чистый экспорт документа).
- **API v2.** Публичные типы без изменений.
- **Статус.** Покрыто.

### B2. Живые ноды документа

- **Что делает.** Объект документа представлен нодой: перемещение,
  мировая позиция и габариты, материалы, анимации; изменения сразу видны в
  сцене, для glTF — без пересборки.
- **Где.** `EN/lib/src/engine/game_scene.dart:494-620`;
  `PD/lib/src/pet/pet_controller.dart:79-134`.
- **API v2.** `ModelNode` (живой, двусторонний) с `kind`, `object`,
  `worldPosition`, `worldBounds`, `setPlacement`, `setWorldPlacement`,
  `play`, `animation`, `animationClips`.
- **Статус.** Частично (в контракте нет перечисленных членов).

### B3. Добавление и удаление объектов через ноды

- **Что делает.** Появление объекта = добавление ноды, исчезновение =
  удаление; документ меняется синхронно, что позволяет редактору снимать
  снимки для отмены.
- **Где.** `ED/lib/src/state/app_state.dart:855-905,1154-1194,1332-1447`.
- **API v2.** `SceneController.addObject/removeObject`,
  `ModelNode.remove()`.
- **Статус.** Частично.

### B4. Свойства объектов

- **Что делает.** Размеры, флаги, скругление (`roundR`, `roundSegments`),
  имя, повороты по трём осям, масштаб, позиция.
- **Где.** `EN/lib/src/models/model_scene.dart`;
  `ED/lib/src/state/app_state.dart:697-759`;
  `EX/lib/src/features/primitives_all.dart`, `rounded_box.dart`.
- **API v2.** Поля `ModelNode`; углы — в градусах на уровне документа и в
  радианах на уровне трансформа, преобразование внутри.
- **Статус.** Частично.

### B5. Группы объектов

- **Что делает.** Именованные группы, дерево, перенос объектов между
  группами, групповые операции.
- **Где.** `ED/lib/src/state/app_state.dart:1564-1824`;
  `ED/lib/src/ui/left_panel.dart:743-915`.
- **API v2.** `ModelGroup` в документе и `GroupNode` в сцене.
- **Статус.** Нет.

### B6. CSG

- **Что делает.** Объединение, вычитание, пересечение твёрдых объектов,
  вложенные операции, каскадное удаление, смена порядка операндов.
- **Где.** `EN/lib/src/scene/csg.dart`;
  `EX/lib/src/features/csg_ops.dart:67-150`;
  `ED/lib/src/state/app_state.dart:1196-1447`.
- **API v2.** Документ хранит csg; нода представляет результат целиком.
- **Статус.** Частично.

### B7. Вставки `model` и `gltf`

- **Что делает.** Объект-ссылка на другую сцену или glTF-ресурс: размеры,
  поворот, масштаб, анимация, защита от циклов, кэш габаритов, замена
  источника, заглушка при потере ресурса.
- **Где.** `EN/lib/src/scene/model_renderer.dart`;
  `EX/lib/src/features/model_refs.dart`, `gltf_models.dart`;
  `ED/lib/src/state/app_state.dart:907-1152`.
- **API v2.** `ModelNode` + `SceneController.insertModel/insertGltf`,
  защита от циклов, заглушка.
- **Статус.** Частично.

### B8. Материалы граней и UV

- **Что делает.** Материал на объект или на отдельную грань; параметры UV:
  направление, отражение, растяжение/тайлинг, масштаб тайлов, сторона.
- **Где.** `EN/lib/src/models/model_scene.dart:158-265`;
  `ED/lib/src/ui/right_panel.dart:1392-1604`;
  `EX/lib/src/features/primitives_textured.dart`.
- **API v2.** `ModelNode.setFaceMaterial`, `SceneMaterial` с UV-полями.
- **Статус.** Частично.

### B9. Мета-объекты

- **Что делает.** Комментарии, маркеры, боксы: размеры, z-порядок,
  схлопывание, имена; используются правилами проходимости и запросами.
- **Где.** `EX/lib/src/features/meta_objects.dart`;
  `ED/lib/src/scene/meta_renderer.dart`;
  `ED/lib/src/state/app_state.dart:570-646,1878-2089`.
- **API v2.** Документ без изменений; рендер мет — редакторский профиль
  (см. M5).
- **Статус.** Нет (в API v2 не описан).

### B10. Поля сцены

- **Что делает.** Входные стороны (`entries`) и лицевая сторона (`front`),
  участвуют в размещении и валидации.
- **Где.** `EN/lib/src/models/model_scene.dart` (`ModelSide`);
  `ED/lib/src/state/app_state.dart:536-568`;
  `MQ/lib/mechanics/model_passages.dart:10,31-42`.
- **API v2.** Остаются в документе; редактор и игра читают через
  `ScenePlacement`.
- **Статус.** Покрыто (документом).

### B11. Свет документа

- **Что делает.** Источники света сцены (точечные и направленные),
  конфигурация освещения: ambient, SSAO, тени, показ гизмо; дефолтный риг
  «солнце + лампа на камере».
- **Где.** `EN/lib/src/engine/game_scene.dart:244-322,392-441`;
  `EX/lib/src/features/lights_sources.dart`;
  `ED/lib/src/scene/light_renderer.dart`;
  `ED/lib/src/scene/editor_scene.dart:1425-1515`.
- **API v2.** `LightNode` (точечный/направленный), `applyLighting`,
  `QualitySettings` (SSAO/тени).
- **Статус.** Частично.

### B12. Шаблоны дома и комнаты

- **Что делает.** Генерация типовых сцен: дом (прямоугольный, П-, Н-образный)
  и комната с проёмами и мебелью.
- **Где.** `ED/lib/src/services/house_template.dart`,
  `room_template.dart`; `ED/lib/src/ui/house_template_dialog.dart`.
- **API v2.** Остаётся в редакторе, строится на документе и `BuildOps`.
- **Статус.** Вне API движка.

## C. Ноды и примитивы

### C1. Базовая нода

- **Что делает.** Идентификатор, имя, слой, признак «на сцене», ссылка на
  контроллер, родитель и дети, видимость, прозрачность, трансформация
  (матрица и отдельно позиция/поворот/масштаб).
- **Где.** `EN/lib/src/render/engine_node.dart`;
  `ED/lib/src/scene/editor_scene.dart:1440,1663-1718`;
  `MQ/lib/engine/impl/scene_builder.dart:299-300,3132`.
- **API v2.** `SceneNode` с `parent`, `children`, `layer`, `transform`.
- **Статус.** Частично.

### C2. Примитивы

- **Что делает.** Куб, скруглённый куб, трапеция, цилиндр, конус, сфера,
  плоскость (вертикальная и горизонтальная), кольцо; мировые UV, тайлинг,
  совмещение углов, намотка граней.
- **Где.** `EN/lib/src/render/engine_mesh.dart`, `primitive_batch.dart`;
  `MQ/lib/engine/impl/scene_builder.dart:1592-2529`;
  `EX/lib/src/features/primitives_all.dart`, `rounded_box.dart`.
- **API v2.** `BoxNode`, `PlaneNode`, `MeshNode`, `SceneGeometry`,
  `GeometryBuilder`.
- **Статус.** Частично.

### C3. Многоматериальный меш

- **Что делает.** Один объект с несколькими частями и материалами
  (например, ядро стены и наружная «кожа»).
- **Где.** `EN/lib/src/render/engine_mesh.dart:47-68`;
  `MQ/lib/engine/impl/scene_builder.dart:2186-2230`.
- **API v2.** `MeshNode` с частями: `geometry` + `material` на каждую часть.
- **Статус.** Нет.

### C4. Спрайт и декали

- **Что делает.** Вертикальная карточка с текстурой: билборд или
  фиксированная; ширина, высота, поворот, цвет, прозрачность, подсветка;
  настенные, напольные и потолочные декали.
- **Где.** `EN/lib/src/render/engine_scene.dart:195-276`;
  `MQ/lib/engine/impl/scene_graph.dart:36-137`.
- **API v2.** `SpriteNode` с ориентациями.
- **Статус.** Частично.

### C5. Линейная геометрия

- **Что делает.** Сетка, рамки, контуры выделения, кольца гизмо, рёбра
  боксов разметки — всё рисуется линиями.
- **Где.** `FS/lib/src/geometry_builder.dart` (`LineSegmentsGeometry`);
  `ED/lib/src/scene/geometry_utils.dart:94-102`.
- **API v2.** `LineGeometry`/`LineNode` без типов форка.
- **Статус.** Нет.

### C6. Свет-нода

- **Что делает.** Точечный и направленный свет: цвет, интенсивность,
  радиус, направление, тени; включение/снятие источников; изменение на

## 22. Многогранники (ветка `feature/polyhedra`)

Добавлено 14 сентября 2026 как подготовка к переносу карт из WAD (будущий
конвертер — отдельная задача) и для правки произвольной геометрии в
редакторе. Номера — продолжение сквозной нумерации разделов реестра.

### B13. Вид документа `polyhedron`

- **Что делает.** Хранит произвольную сеть: индексные вершины, плоские
  n-угольные грани (вогнутые и с дырками), явные UV на контурах,
  неоднородный масштаб `scale: [x,y,z]`. Рендер, пикинг по граням и
  материалы по граням работают как у примитивов.
