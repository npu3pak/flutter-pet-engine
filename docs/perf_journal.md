# Журнал производительности pet_engine

Замеры и разбор узких мест. Живой журнал: приложение-пример дописывает сюда
результаты стресс-теста уровневого слоя (раздел 2). Замеры драга гизмо
делает харнесс `pet.perf.drag` в приложении с редакторским вьюпортом;
методика и полные таблицы — в журнале производительности такого приложения.

## 1. Быстрые пути обновления сцены (13 сентября 2026)

Задача — «очень медленное обновление сцен при перемещении объектов». Замер
на сцене `Pet/model_2` (24 объекта, 9335 частей, 120 нод) показал: вставка
модели, спрайт и glTF пересобирали всю сцену на каждый шаг драга (53 мс
синхронно, `ModelRenderer.rebuild` 50–120 мс), куб шёл быстрым путём
(0.6 мс). Сделано:

- **Трансформационный быстрый путь.** `ModelRenderer.updateObjectTransforms`
  принимает `translated`/`rotated`: ноды элементов сдвигаются или
  поворачиваются приписыванием мировой префиксной матрицы к текущей
  локальной — без геометрии, CSG, материалов и пересборки. Для запечённых с
  зеркалом X вершин (скругления, CSG) префикс сопрягается `M·Δ·M`; цепочки
  билбордов внутри вставок обновляются вместе с нодами.
- **Поворот без пересборки.** Шаг поворота — модельный `R_new·R_old⁻¹`;
  мировой префикс строится вокруг якоря объекта (`T(anchor)·Δ·T(−anchor)`).
- **CSG.** Результат операции двигается шагом первого операнда (его ноды
  зарегистрированы под id операции); раньше он перестраивался только на
  отпускании — это был баг корректности, а не только перф.
- **Идемпотентный свет.** `applyLighting` сравнивает подпись конфигурации и
  не пересобирает свет при том же документе; `setShadows`/`setSsao`/
  `setEnvironmentIntensity` — no-op при том же значении.
- **Wireframe** обновляется только по перемещённым элементам.
- **Диагностика.** `SceneController.rebuildCount` — счётчик полных
  пересборок для регрессионных тестов «драг не пересобирает сцену»;
  `hitGizmo` не проверяет скрытые гизмо (исправлен перехват кликов).

Результат: перенос и поворот вставки, спрайта и glTF — 53 мс → 0.3–0.4 мс
(поворот — 0.10 мс), полных пересборок за драг — 0. Тесты:
`test/fast_rotate_test.dart` и регрессии приложения с редакторским
вьюпортом.
