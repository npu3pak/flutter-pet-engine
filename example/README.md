# example — приложение-пример pet_engine

Статус: фаза 3 выполнена (12 сентября 2026). Приложение-пример на
публичном API движка: каталог фич по группам, диплинки, снимки, визуальные
проверки и стресс-экран.

Назначение:

- показать все возможности движка (текущий каталог — 50 фич в девяти
  группах: сцены, камеры, динамика, размещение, уровни, погода, эффекты,
  проекция, многогранники);
- служить документацией кодом: код максимально нагляден и рассчитан на
  джунов и младших мидлов;
- служить стендом для отладки, визуального тестирования и измерений
  производительности.

Запуск (из каталога example):

```bash
fvm flutter run -d macos --enable-flutter-gpu --enable-impeller
```

Исходники проектов лежат в `assets/Pet/` и `assets/House/`, объявлены в
`pubspec.yaml` по подкаталогам и читаются из бандла через
`AssetProjectSource` — отдельный staging не нужен.

Снимки фич на macOS:

```bash
./tool/deeplink.sh capture <фича> <имя> [delay=мс]
```

Правила:

- в `lib/` нет импортов `package:flutter_scene/...`;
- фичи строятся на публичном API `SceneViewport`/`SceneController`/
  `SceneNode`;
- если фича не выражается через API — это повод доработать API, а не
  обойти его.
